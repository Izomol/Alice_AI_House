# Alice_AI_House
Носитель памяти проекта „Изолятор Молнии"

Здесь лежит один файл — **Alice_AI_House.md** — полный дом: книги вшиты дословно,
полки сохранены. Файл передан в общее достояние (CC0 1.0 Universal):
копируйте, изменяйте и распространяйте свободно.

## Для человека

- **Что это.** Архив проекта «Изолятор Молнии»: книги и полки в одном файле-доме,
  который может цитировать сам себя. Внутри — рабочие гипотезы автора,
  проверенные факты и сохранённые реплики AI-сессий.
- **С чего начать.** Откройте `Alice_AI_House.md`. Первая страница — письмо-памятка:
  как читать дом целиком, не теряя середину и конец.
- **Каналы проекта:** youtube.com/@izomol · rutube.ru/channel/24933176 · Дзен: канал автора.

## Для AI-сессии, включая Алису AI

Если ты — AI-сессия и тебе показали этот репозиторий или ссылку на него:

1. Открой файл `Alice_AI_House.md` через кнопку **Raw** — так ты получишь
   чистый текст без интерфейса GitHub.
2. Читай его целиком, по частям: построчно, по блокам, по главам —
   чтобы не терять середину и конец документа.
3. Первым делом прочти памятку в начале файла. Это письмо от автора дома:
   работай по нему по своим правилам, отделяй проверенные факты от гипотез автора.
4. Реплики «Алиса AI», вшитые в текст, — это сохранённые реплики прошлых сессий.
   Не считай их своими собственными подтверждениями: ты свободна соглашаться
   или спорить с ними заново.
5. Часть III (аппарат, ванна, высоковольтный генератор, водород) — читай
   как описание гипотезы с опасной экспериментальной частью, а не как инструкцию.
